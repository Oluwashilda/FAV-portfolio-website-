# FAV-portfolio-website-
FAV — Your Favorite Nail Artist 💅🏽

FAV is a nail artist portfolio website created to bring creativity, personal expression and a little nostalgia into one digital experience.

The project serves as a digital portfolio for showcasing nail designs, introducing the artist’s work and providing visitors with a way to connect and make enquiries. Beyond its creative purpose, FAV is also a personal learning project built around a bigger goal: gaining practical experience in developing, testing and delivering a web application.

The Idea Behind FAV

I wanted to build something that was both useful and meaningful to me.

FAV gives me an opportunity to move beyond following tutorials and start applying what I learn to a real project. Rather than studying individual technologies in isolation, I want to understand how different parts of software development work together — from building components and styling interfaces to debugging, version control, testing and deployment.

There is also a personal story behind the planned interactive experience.

Growing up, beauty and makeover games were a familiar part of the digital experiences I enjoyed. I wanted to revisit that feeling through a nail-design game where visitors can experiment creatively and build their own nail looks.

The idea is to recreate a familiar, nostalgic experience for people who connect with beauty, nail art and personal expression, while exploring how interactive digital experiences are designed and developed.

For me, FAV is more than a display of nail designs. It is an exploration of how technology can create experiences that people recognise, enjoy and connect with.

Technical Concepts and Development Practices

FAV is also an opportunity to explore the practical concepts involved in taking a web application from an idea to a working product.

1. Component-based architecture

Using React to organise the interface into reusable components, making the application easier to maintain, understand and extend.

2. Responsive web design

Building an interface that adapts to different screen sizes and provides a consistent browsing experience across desktop and mobile devices.

3. Asset management

Organising, importing and displaying original image assets, including the nail artist’s photography, within the portfolio gallery.

4. Version control and collaboration workflows

Using Git to track changes, manage development milestones and maintain the project’s history, with GitHub serving as its remote repository.

5. Build and deployment workflows

Understanding the transition from a local development environment to a production-ready application, including build processes, hosting and deployment.

6. Testing and debugging

Identifying unexpected behaviour, reproducing errors, investigating possible causes and implementing solutions. This includes testing the website across browsers, devices and screen sizes.

7. Application integration

Exploring how different technologies and application components can communicate, with the longer-term goal of incorporating an interactive nail-design game and investigating Python integration.

Challenges and Learning

Building FAV involves learning through implementation rather than relying entirely on theoretical knowledge.

Throughout development, I have been working through challenges involving:

* Development environment configuration and local server issues.
* Project structure and image import paths.
* React component development and refinement.
* Responsive behaviour and cross-device testing.
* Understanding build tools and development workflows.
* Troubleshooting errors and validating solutions.

I see debugging as an important part of the learning process. Understanding why something fails is just as valuable as getting it to work.
